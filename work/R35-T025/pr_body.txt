# PR Title
R35-T025: Isolate Text Recognition inference and add repeatability checks

## Summary

Expose Text Recognition as `recognize_text(image_url)`, return the decoded text,
and keep each image/processor/model invocation local to that call.
<!--give a short summary of your changes you made in the repository -->

## Description

The notebook previously used a fixed URL and assigned image/model intermediates
in shared notebook state. The new helper takes the image URL explicitly and
returns the first decoded transcription; the notebook now uses this helper.
The README documents its input, result, state behavior, and runtime
dependencies. Focused tests mock HTTP, image decoding, and Transformers so they
do not download a real image or model.

### The changes are as follows:
- Add `Text Recognition/text_recognition.py` with the reusable inference
  function and default image URL.
- Update the notebook and README to use and document the function.
- Add repeatability, input/result, and error-propagation checks, including the
  same fixture twice in fresh state and again after another valid input.
- Save the pre-change contract, fixtures and expected/actual results, test
  output, and tool versions in `work/R35-T025/`.
