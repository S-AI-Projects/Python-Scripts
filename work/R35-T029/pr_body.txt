## Summary

Repair the macOS Website Blocker module so it imports safely, and add focused checks plus reproducible operation-count measurements for its host-line filtering.

## Description

The original file contained HTML-escaped tokens and did not compile. Its infinite loop also ran at import time, preventing focused tests. The corrected script keeps the host-file behavior behind `main()` and extracts a pure line-filter helper. Checks only import the named module and mock file I/O.
<!-- Description of your changes in detail in a better understandable way-->

### The changes are as follows:
- Repair the Python syntax and guard the host-file loop so importing the module does not access `/etc/hosts`.
- Verify that the filtering helper removes matching lines and preserves its input.
- Measure substring checks for 100, 1,000, and 5,000 host lines, using fixed seeds, fresh inputs, and five repetitions per size. Median and range: 100 lines — 541 (537–584); 1,000 — 5,479 (5,438–5,527); 5,000 — 27,378 (27,309–27,476).
- Runner: [check.py](https://github.com/riya1503235/Python-Scripts/blob/R35-T029/work/R35-T029/check.py). Inputs, expected/actual results, measurements, and tool versions: [results.json](https://github.com/riya1503235/Python-Scripts/blob/R35-T029/work/R35-T029/results.json).
