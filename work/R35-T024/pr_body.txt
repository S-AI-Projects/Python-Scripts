# PR Title
R35-T024: Keep JSON values aligned with CSV headers

## Summary

Use the first employee record's header order when writing every CSV row, so
records with the same keys in a different JSON key order remain aligned.

## Description

The script reads `data.json`, selects `emp_details` (source lines 7 and 9),
iterates its employee objects (line 21), and uses the first object's keys for
the CSV header (line 25). It previously wrote later objects' values in their
own key order (line 30). The focused checks use literal minimal and ordinary
fixtures plus 128 bounded valid cases with a fixed seed; file I/O is mocked.

### The changes are as follows:
- Write each employee's values by the header keys established by the first
  employee.
- Add 130 focused pytest cases, including 128 fixed-seed generated records
  with common keys and varied insertion order.
- Add `work/R35-T024/check.py` and record every input, expected CSV, actual
  CSV, tool versions, and test output in `work/R35-T024/`.
