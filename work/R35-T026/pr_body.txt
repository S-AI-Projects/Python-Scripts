# PR Title
R35-T026: Extract QR logo sizing into a focused helper

## Summary

Extract the contiguous logo-resizing responsibility into `resize_logo` while
preserving the existing resize algorithm and script behavior.
<!--give a short summary of your changes you made in the repository -->

## Description

The script still reads the same local logo, encodes the same URL, creates the
same QR code, centers and pastes the resized logo, saves the same output file,
and prints the same message. The extracted helper takes the loaded logo image
and returns the result of the same Pillow `resize` call. No external image or
network access is used by the focused tests.

### The changes are as follows:
- Extract the fixed-width aspect-ratio calculation and Pillow resize into
  `resize_logo(logo_img)`.
- Add a pre-change characterization check for the script's image/QR call
  order, centered paste, output path, and printed result.
- Verify the helper's dimensions and image return type; mock qrcode and Pillow
  file/image operations.
- Save the baseline contract, test fixtures and expected/actual results, test
  output, and tool versions in `work/R35-T026/`.
